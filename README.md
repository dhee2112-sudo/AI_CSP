# AI Assignment 4 – Constraint Satisfaction Problems (CSP)

## Overview
This project implements CSP problems using Python.

## Problems Implemented

### 1. Australia Map Coloring
- States: WA, NT, Q, SA, NSW, V, T
- Constraint: Adjacent states must have different colors

### 2. Telangana Map Coloring
- 33 districts
- Uses 4 colors (based on CSP theory)
- Graph-based visualization

### 3. Sudoku Solver
- Solves 9x9 Sudoku using backtracking
- Constraints:
  - Row
  - Column
  - 3x3 grid

### 4. Cryptarithmetic Puzzle
Problem:
SEND + MORE = MONEY

Constraints:
- Unique digits
- No leading zero
- Valid arithmetic
